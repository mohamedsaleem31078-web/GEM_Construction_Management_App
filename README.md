# GEM Construction Management App 🏗️

A professional-grade, high-performance web application designed specifically for Senior Construction Managers, Resident Engineers, and QA/QC teams to streamline site operations, track daily progress, manage non-conformance reports (NCR), and monitor finishing defects.

## 🌟 Key Features
- **Daily Progress Tracking:** Real-time logging of site activities, subcontractor performance, and weather conditions.
- **QA/QC & Snag List Module:** Digital tracking of site defects, material submittals, and inspection requests.
- **Professional UI/UX:** Built with clean, modern dark/light themes tailored for engineering environments.
- **Automated Dashboards:** Instant visibility over critical path delays and milestone achievements.

## 🛠️ Technology Stack
- **Frontend:** HTML5, Modern CSS3, JavaScript (ES6+)
- **Architecture:** Responsive, mobile-friendly layout optimized for site tablets and desktop displays.
